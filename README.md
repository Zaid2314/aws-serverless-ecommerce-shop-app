# AWS Serverless E-Commerce Shop App

A full-stack e-commerce mobile application built using Flutter and AWS Serverless technologies. The application follows a microservices architecture and leverages AWS services such as Lambda, API Gateway, DynamoDB, S3, and Cognito to deliver a scalable, cloud-native shopping experience.

## Features

* User Authentication & Authorization using AWS Cognito
* User Sign Up, Sign In and Account Management
* Category Management System
* Product Management System
* Banner Management
* Secure Image Uploads using Amazon S3 Pre-Signed URLs
* RESTful APIs using AWS Lambda and API Gateway
* Cloud-Native Serverless Architecture
* Responsive Flutter Mobile Application
